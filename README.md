## 🎨 Creative Direction: The Digital Workshop

Engineered with an original editorial aesthetic inspired by modern digital publications, systems telemetry, and technical craft:
- **Surfaces**: Warm ivory (`#FAF9F5`) and layered off-whites (`#F3F1EA`) with 1px architectural lines.
- **Accents**: High-energy electric-lime (`#CEFF1A`) for verified telemetry badges and calls to action.
- **Dark Contrast Blocks**: Deep charcoal (`#0E0F12`) for high-impact project showcases and the contact outro.
- **Typography System**: 
  - Display: **Space Grotesk**
  - Body: **Plus Jakarta Sans**
  - Data / Telemetry: **IBM Plex Mono**
- **Interactive Signature Canvas**: Physics-driven interconnected node-and-system neural graph reacting smoothly to pointer movement.

## ⚡ How to Run Locally

You can run this project locally without any complex build tools or runtime installations:

### Option 1: Python Built-In HTTP Server (Recommended)
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in any browser.

### Option 2: VS Code Live Server
Right-click `index.html` in VS Code and select **"Open with Live Server"**.

### Option 3: Direct File Opening
Double-click `index.html` in your file manager.

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Commit and push changes to the `main` branch of your GitHub repository:
```bash
git add .
git commit -m "Build world-class editorial developer portfolio & case studies"
git push origin main
```
2. Navigate to your repository on GitHub:
   - **Settings** → **Pages**
   - **Source**: Deploy from a branch
   - **Branch**: `main` / `(root)`
   - Click **Save**
3. Your portfolio will be live at:
   `https://buildwithneel.github.io/Portfolio/`
