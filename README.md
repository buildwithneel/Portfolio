## 🌐 Deploy to GitHub Pages (Free Hosting)

```bash
git init
git add .
git commit -m "Deploy Neel Agrawal Personal Portfolio"
git branch -M main
git remote add origin https://github.com/buildwithneel/portfolio.git
git push -u origin main
```

Enable GitHub Pages under **Repository Settings -> Pages -> Source: main branch / (root)**.
Your website will be live at: `https://buildwithneel.github.io/portfolio/`
