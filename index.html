Projects

Anvesha

Anvesha is an AI-powered railway station CCTV monitoring concept developed as a solution for an internal institute-level SIH problem statement. It is designed to use existing CCTV infrastructure to monitor railway stations and identify situations such as unusual crowd buildup and potential security concerns, with the goal of alerting railway authorities for faster response.

AI/ML Computer Vision CCTV Monitoring Railway Safety

Saarthi AI

Saarthi AI is an AI-based counselling concept designed for college students. The project explores how AI can provide accessible guidance and support to students while addressing common academic and student-life concerns. It was developed as a hackathon project and is currently not fully functional, but the project demonstrates the idea of using AI to create a student-focused counselling platform.

AI Student Support Counselling Hackathon Project

Garuda AI

Garuda AI is a cybersecurity-focused project developed for FinSpark '26, exploring the detection of potential insider threats. The project focuses on identifying suspicious or potentially malicious behavior from within an organization and using intelligent analysis to support threat detection.

AI/ML Cybersecurity Insider Threat Detection Security Analytics
View on GitHub

Ghost Chat

Ghost Chat is an experimental privacy-focused chatting concept built around the idea of communicating without requiring users to share personal identifiers such as phone numbers or social-media IDs. The long-term vision is to create a platform where users can communicate privately without exposing unnecessary personal details, with messages designed not to remain stored on devices after the user logs out. The current implementation is not fully functional and should be presented as an experimental project/concept rather than a finished product.

Privacy Communication Web Development Experimental Project
