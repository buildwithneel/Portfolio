Ghost Chat: Zero-Identity Ephemeral Web Communications

An experimental lightweight communication architecture built around zero user identifiers, peer-room ephemeral states, and memory-only storage that leaves zero persistent footprints upon session close.

1. The Problem

Nearly every mainstream messaging tool demands invasive phone number verification, email harvesting, contacts synchronization, and persistent cloud backup retention. Even for temporary, ad-hoc conversations, users leave permanent metadata trails, device fingerprints, and synchronized message histories that outlive the conversation by years.

2. Architectural Principles

Ghost Chat explores a radical minimization model:

Zero Identifiers Required

No phone numbers, no emails, no account registration. Rooms are joined via randomized one-time session hashes.

RAM-Only Transience

Messages exist exclusively in volatile memory for active peers. No relational database, no disk logging, and no persistent device storage.

Instant Session Annihilation

Closing the browser tab purges local crypto keys and memory buffers immediately.

3. Current Status & Honest Evidence

Honest Status Disclosure

Ghost Chat is maintained as an experimental sandbox exploring ephemeral web state and privacy concepts. As documented in Neel's portfolio, it should be recognized as an exploratory prototype rather than a commercially hardened enterprise messaging system.
